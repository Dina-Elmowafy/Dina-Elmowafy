### 🛡️ [Fraud Detection System](https://github.com/Dina-Elmowafy/Fraud-Detection-System)
> **Enterprise-level banking API designed to evaluate transfers and block suspicious transactions.**
- 🏗️ **Architecture:** Designed an extensible `FraudRule` strategy using Spring DI for high-value and velocity checks.
- ⚙️ **Core Features:** Implemented **idempotency keys** for safe retries and **pessimistic write locking** for concurrent account updates.
- 🔒 **Security & Logging:** Persisted `FraudAlert` and `AuditLog` records with no-rollback transaction management.
